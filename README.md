# Libft

A custom C library implementing a set of standard functions as well as additional utility functions.

## Description

Libft is a reimplementation of parts of the C standard library, along with extra helper functions commonly used in C projects. It is designed to deepen understanding of memory management, strings, and data structures in C.

## Features

- Memory functions (memset, memcpy, memmove, etc.)
- String functions (strlen, strdup, strchr, etc.)
- Character checks (isalpha, isdigit, etc.)
- Conversion functions (atoi, itoa, etc.)
- File descriptor output functions (putchar_fd, putstr_fd, etc.)
- Linked list utilities (bonus)
